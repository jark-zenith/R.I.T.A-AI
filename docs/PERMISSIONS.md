# R.I.T.A Permissions

| Scope | Meaning | Money movement |
| --- | --- | --- |
| finance:read | Read authorized financial information | No |
| finance:write | Create or update manual records | No |
| finance:reconcile | Reconcile records | No |
| finance:report | Generate financial reports | No |
| finance:action:request | Prepare a possible future external action | No |

There is intentionally no execution scope in the MVP.
